HR MANAGER v4
Aplicație PWA instalabilă pe telefon.

Ce include:
- angajați
- expirări medical/SSM
- task-uri și termene
- calendar
- centru de notificări
- atașare PDF locală
- backup/import JSON
- instalare ca aplicație (PWA)
- funcționare offline după prima încărcare

IMPORTANT:
Pentru notificări garantate când aplicația este complet închisă și pentru date sincronizate între telefon și calculator, este necesar un backend/cloud. Această versiune este pregătită pentru acest pas, dar datele rămân local până la conectarea unui serviciu online.

Pentru testarea instalării PWA, aplicația trebuie servită prin HTTPS sau localhost; deschiderea directă a fișierului index.html poate să nu permită instalarea/service worker.
